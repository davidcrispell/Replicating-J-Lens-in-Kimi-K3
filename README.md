# Replicating-J-Lens-in-Kimi-K3

There is no publicly available J-Lens for Kimi K3. Kimi K3 is a very large (2.8T), very intelligent open-weights model. It offers these characteristics to the public safety community uniquely, as other similarly performant models are closed-weights. Unfortunately, there has yet to be a publicly released J-lens checkpoint for K3. 

This project would first replicate the J-lens in K3 (likely, as written in https://fireworks.ai/blog/J-Lens-Kimi-K3-Qwen, who replicate but do not expose the checkpoint), then release the code and trained J-lens. 

## Status

This project is currently unfunded, but is a problem which can be solved easily with compute.
